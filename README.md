# Bubble Breach

A modern take on Pang / Bubble Trouble. Harpoon the orbs, chain air streaks, and hit an armed lime pair to shoot its twin.

**▶ Play in your browser (PC or phone):** https://federallyapproved.github.io/bubble-breach/

**Downloads** (latest release):
- Android: `BubbleBreach.apk` (Android 7+; allow "install unknown apps")
- Windows: `BubbleBreach_Windows.zip` → unzip, run `BubbleBreach.exe` (SmartScreen: More info → Run anyway)

Controls: A/D or ←/→ move · Space/W/↑ fire · Esc pause · F11 fullscreen. On phones: on-screen ◀ ▶ FIRE.
